How the encryption works

  • encrypted location
  • secret key (URL fragment only)
  1. Your browser generates a random AES-256 key locally and puts it only in the share link's URL fragment, which browsers never send to any server.
  2. Every GPS update is encrypted on your device before it's sent — the backend and its database only ever store ciphertext.
  3. Anyone with your link decrypts each update locally in their own browser, so only they — never the server — can see where you are.
