2. Purpose and target audience
------------------------------
privIsee lets people share their live GPS location with chosen contacts for a limited
time, through a link, without giving the location to anyone else, including us as the
operator.

Problem it solves: most location-sharing apps send exact positions to their servers,
where they can be stored, analysed or leaked, and often need an account on both sides.
privIsee encrypts every position on the device (AES-256-GCM) before sending it. The
decryption key is only in the link fragment (after "#"), which browsers never send to a
server, so our server only stores ciphertext. It keeps no location history; each update
overwrites the previous one, and expired shares are deleted automatically.

Value: you can be found by the right people (friends at a festival, family while you
walk home, someone picking you up, hiking or running partners) without being tracked.
The recipient needs no app and no account, because the link opens in any browser.

Target audience: adults (16+) who want to share their location temporarily with
people they trust and care about privacy. The app is not directed at children.


3. Setup and access instructions
--------------------------------
No login, credentials or sample files are needed.

  1. Open privIsee.
  2. Pick how long you want to be findable (e.g. 15 minutes).
  3. Tap "Go live" and allow location access when iOS asks.
  4. Tap "Copy link" (or share it) and open the link in Safari or on a second device.
     Your position appears as a live dot on the map and updates every few seconds.
  5. Optional: on the map page, tap the directions button to open a route to the shared
     position.
  6. Tap "Go dark" to stop sharing. The link then shows that the share has ended.

Tip for testing on a simulator or a stationary device: the map shows the current
position. Moving around (or simulating a location) shows the live updates.

4. External services used
-------------------------
privIsee uses no authentication service, payment processor, analytics, advertising
or AI service. It uses these external services:

  - IONOS SE (Germany, EU data centers): hosts the web app and the backend REST API and
    MySQL database. It stores only encrypted location data, a random share ID and a
    random owner token.
  - Esri ArcGIS (server.arcgisonline.com): map background tiles shown on the share/map page.
  - unpkg CDN (on Cloudflare infrastructure): delivers the open-source map library
    Leaflet 1.9.4.
  - Google Fonts: web fonts "Space Grotesk" and "Space Mono".
  - OpenStreetMap (openstreetmap.org/directions): opened only when a viewer taps the
    directions button (on Android, the device's own maps app is used instead).
  - Apple Core Location / device location services, through the system location API.
  - Encryption uses the platform's built-in Web Crypto API (no third-party crypto service).
